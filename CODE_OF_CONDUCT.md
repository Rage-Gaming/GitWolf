# Code of Conduct

We want GitWolf to be a welcoming, harassment-free community for everyone, regardless of
experience, background, identity or beliefs.

## Expected behaviour

- Be respectful and constructive. Assume good intent.
- Give and accept feedback graciously.
- Focus on what is best for the project and community.

## Unacceptable behaviour

- Harassment, discrimination, insults, or personal attacks
- Unwelcome sexual attention or imagery
- Publishing others' private information
- Any conduct that would reasonably be considered inappropriate in a professional setting

## Enforcement

Maintainers may remove, edit or reject contributions that violate this code and may temporarily
or permanently ban contributors for behaviour they judge inappropriate. Report concerns by
opening a private security advisory on the repository or contacting the maintainers directly.
